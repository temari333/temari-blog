婚姻届の記事で書いたとおり、わが家は入籍が先。彼の実家は和歌山で、なかなか行けなかったんです。付き合って3年、入籍してからの「はじめまして」でした。2泊3日のご挨拶で、準備してよかったこと、失敗したことをまとめます。

01移動と宿：行くまでに疲れた話

東京から新大阪までは新幹線、そこからは普通列車で和歌山へ。たしか4〜5時間くらいかかったと思います。正直、着く前にもう疲れてました（笑）。

これから行く人へ

新大阪から和歌山へは、特急「くろしお」なら約1時間で着きます。ご挨拶の前に体力を使いたくない人は、特急を使うのもありです。

宿は「駅近」がいちばんラク

現地ではレンタカーを借りる予定だったので、「もう駅の近くがいいね」となってホテルグランヴィア和歌山に泊まりました。JR和歌山駅からすぐの、老舗っぽいホテルです。

建物は少し古かったけど、行きも帰りもラクで、寝るだけだから十分。そんなに高くなかったのもよかったです。

私たちが泊まったホテル

PR
ホテルグランヴィア和歌山

JR和歌山駅から徒歩約2分。レンタカーを借りるにも、帰りの電車に乗るにも便利な場所でした。

楽天トラベルで見る

02手土産：彼にこっそり聞いてもらった

手土産は、事前に彼からご家族の好みをこっそり聞いてもらいました。甘いものが好きと聞いて、お煎餅の間にチョコやクリームが挟まったお菓子と、クッキー缶にしました。

わたし
…でも暑くて、チョコが溶けちゃってたんです。喜んではもらえたけど、これは失敗でした。
ここ注意

移動が長いときや暑い時期は、チョコなど溶けやすいものは避けるのが安心。季節と気温、移動時間まで考えて選んでね。

暑い時期でも安心な手土産なら

PR
プルミエール「メルシーボックス」

東京の洋菓子店プルミエールのクッキー詰め合わせ。スノーボールやショコラサブレなど3種のクッキーに、ハーブティーもセットになっています。常温保存で日持ちは発送から約30日なので、遠方へ持っていく手土産にぴったり。ポメラニアン柄のパッケージもかわいいです。

楽天市場で見る

03服装とメイク：清楚系でいけば大丈夫

服装はすごく悩みました。レンタルも考えたけど、汗をかくし…ということで、キレイめのワンピースに決定。明るめのアイボリーっぽい色です。

  • 髪：ふんわり巻く
  • メイク：ナチュラルめ
  • 赤み対策：緊張すると顔が赤くなるので、グリーンベースの下地を仕込みました
  • 唇の保湿：緊張すると唇が乾燥するので、保湿は必須（笑）

わたしが仕込んだグリーン下地

PR
d プログラム 薬用スキンケアベースCC ブルーグリーン

資生堂の敏感肌ブランドの薬用化粧下地。ブルーグリーンは赤みやニキビ跡をカバーしてくれる色です。緊張で赤くなりやすい人のお守りに。SPF20・PA+++。

楽天市場で見る

緊張で乾く唇に

ラネージュ リップスリーピングマスク

寝る前にたっぷり塗っておくと、翌朝の唇がふっくら。ご挨拶の前の晩に仕込んでおくのがおすすめです。（LANEIGE公式ショップ）

楽天市場で見る
わたしの結論

親世代にもよるけど、清楚系でいけば問題なし（笑）。長い移動や暑さも考えて、汗をかいても大丈夫な服を選ぶのがおすすめです。

04話すのが苦手な私の、当日

いちばん不安だったのが、話すのが得意じゃないこと。質問されてから考えるのに時間がかかるし、うまいことも言えない。なのに、見た目はしっかりしてそうに見られるのがつらいところで…。

わたし
聞きたいことをメモしていったのに、当日は頭が真っ白。無言になっちゃいました。

助かったのは、彼のお母さんとお姉さんがとても優しかったこと。関西の方なのもあって、おしゃべり好きで、たくさん質問してくれたんです。

そして、控えめな感じがむしろ好印象だったみたいで、ほっとしました。

話すのが苦手な人へ

みんなが話し好きなご家族とは限らないので、話題をいくつか持っていくと安心です。たとえば…

  • 彼の子どもの頃の話（聞くと喜ばれやすい）
  • 地元の名物やおすすめの場所
  • 持っていった手土産の話
  • これからの結婚式の予定

05意外と大変だったのは「気疲れ」

せっかく来たから、と彼の友達や後輩にも何人も会いました。楽しかったけど、初めての人ばかりの空間って、やっぱり疲れますよね。

わたし
ホテルに帰ったら、足に休足時間を貼って、最低限のスキンケアだけしてすぐ寝てました。
これは本当におすすめ

ホテルに帰ったらすぐ休める準備をしておくのが大事。足のケアグッズや、オールインワンなど手早く済むスキンケアを持っていくとラクです。

歩き疲れた足に

PR
ライオン 休足時間 足すっきりシート

寝る前に足に貼るだけのひんやりシート。移動と気疲れでパンパンの足が、翌朝ちょっとラクになります。かさばらないので旅行バッグに。

楽天市場で見る

06うれしかったこと

彼の実家では、気に入ってもらえたのか、彼の小さい頃のアルバムを見せてもらったり、昔話を聞かせてもらったりしました。これは本当にうれしかったです。

帰ってからのお礼の連絡は、彼からしてもらいました。誰が連絡するか、事前にふたりで決めておくとスムーズです。

07まとめ＆準備チェックリスト

初めてのご挨拶で、私が伝えたいのはこの3つ。

  1. 手土産は、季節と気温まで考えて選ぶ
  2. 話すのが苦手なら、話題をいくつか用意しておく
  3. ホテルに帰ったら、すぐ休める準備をしておく

緊張して当然。うまく話せなくても、ちゃんと伝わるものはあるよ。
